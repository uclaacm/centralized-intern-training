# Centralized Intern Training

Across the eight different committees that make up ACM, ACM Board and its initiatives, web development is one of the most prominent shared skills used between all of them! More than just the committees that focus on web development (ACM's dev team, TeachLA, and Hack), each committee will also need people to help manage their official website.

This is an asynchronous training program for all interns to learn the basics of web development and get hands-on experience with these technologies. No experience is needed. By the end, you'll know the basics of the frontend and backend tools used in the [ACM website](https://github.com/uclaacm/website) and the [membership portal](https://github.com/uclaacm/membership-portal-ui).

Every module has a lesson and a short project. If you feel like you already have a good grasp of the topic, feel free to skip ahead to the project. If you feel like you need more help, I would encourage you to discuss with your peers, and reach out if you still need help.

## One Project, Built Up Over Time

The projects all build on each other. You'll start with a personal blog made with plain HTML and CSS, and by the end it will be a full stack app, so keep your code from each project! We use [pnpm](https://pnpm.io/) for these projects, starting in week 2.
